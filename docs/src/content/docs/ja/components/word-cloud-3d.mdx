`WordCloud3D` は WebGL（Three.js / Threlte 経由）を使って複数の深度レイヤーにワードをレンダリングします。`Ctrl + Wheel`、ピンチジェスチャー、またはビルトインの深度スクロールバーでレイヤー間を移動できます。スクロール範囲は最後のレイヤーを少し超えて延長されており、そのレイヤーの小さいワードも拡大して確認できます。

`WordCloud` の子孫要素である必要があります。

## Props

| Prop | 型 | デフォルト | 説明 |
| ---- | -- | ---------- | ---- |
| `fontUrl` | `string` | — | **必須。** フォントファイルのURL（TTF/OTF/WOFF）。**セルフホストが必須です。** フォントファイルをプロジェクトの `public/` ディレクトリに配置し、パスを指定してください（例：`'/fonts/MyFont.ttf'`）。なお WOFF2 は非対応のため、TTF・OTF・WOFF をご利用ください。 |
| `wheelScrollSpeed` | `number` | `1` | `Ctrl + Wheel` とピンチ深度スクロールの速度倍率。 |
| `layout` | `WordCloud3DLayout` | `{}` | 配置・サイズに関するオプション（下記参照）。 |
| `a11y` | `WordCloud3DA11y` | `{}` | アクセシビリティラベルと ARIA テキスト（下記参照）。 |
| `onWordClick` | `(word: WordItem) => void` | — | ワードがクリックされたときに呼び出されます。 |
| `useCache` | `string \| symbol \| true` | — | 計算済みレイアウトを `localStorage` に保存します。`true` を指定するとデータとレイアウトパラメータのハッシュからキーを自動生成します。`string` または `symbol` で明示的なキーを指定することも可能です（同一ページに複数のワードクラウドがある場合に便利）。データやパラメータが変更されると自動的に無効化されます。インスタンスの `clearCache()` で手動削除も可能です。 |

### `layout`

| キー | 型 | デフォルト | 説明 |
| ---- | -- | ---------- | ---- |
| `layerSpacing` | `number` | `12` | 隣接レイヤー間の Z 距離（Three.js ワールド単位）。 |
| `fontSizeContrast` | `number` | `2.0` | べき乗カーブの指数。大きいほど上位ワードが突出して大きくなり、小さいほど均一なサイズになります。 |
| `topWordArea` | `number` | `0.22` | 最大ワードが占めるビューポート面積の割合。 |
| `randomness` | `number` | `0.5` | 配置のランダム性。`0` = グリッド状、`1` = 最大散布。 |

### `a11y`

| キー | 型 | デフォルト | 説明 |
| ---- | -- | ---------- | ---- |
| `depthValueText` | `(current: number, total: number) => string` | `` (c, t) => `Layer ${c} / ${t}` `` | ビルトイン深度スライダーの `aria-valuetext`。ローカライズ用。 |
| `depthLabel` | `string` | `'Depth'` | 深度スライダーのアクセシブルラベルテキスト。 |
| `zoomValueText` | `(zoom: number) => string` | `` (z) => `${z.toFixed(1)}x` `` | ビルトインズームスライダーの `aria-valuetext`。ローカライズ用。 |
| `zoomLabel` | `string` | `'Zoom'` | ズームスライダーのアクセシブルラベルテキスト。 |
| `panHint` | `string` | `'Arrow keys to pan'` | キーボードパンコントロールがフォーカスされたときに表示される短いヒントテキスト。 |
| `panLabel` | `string` | `'Pan camera. Use arrow keys to move the view.'` | キーボードパンコントロールボタンのスクリーンリーダー向け説明。 |
| `resetPanLabel` | `string` | `'Reset pan (double-click)'` | パンリセットボタンのスクリーンリーダー向けラベル。 |

## 使い方

```svelte
<script lang="ts">
  import { WordCloud, WordCloud3D, WordCloudLabel } from '@shamokit/svelte-wordcloud';
  import type { WordItem } from '@shamokit/svelte-wordcloud';

  // フォントファイルを public/fonts/ に配置し、パスで参照します。
  // 外部 CDN URL は本番環境でブロックされるため、セルフホストが必要です。
  const FONT_URL = '/fonts/NotoSansJP.ttf';

  const words: WordItem<{ link?: string }>[] = [
    { word: 'Svelte',     counts: 120, link: 'https://svelte.dev' },
    { word: 'TypeScript', counts: 95,  link: 'https://www.typescriptlang.org' },
    { word: 'Vite',       counts: 80,  link: 'https://vitejs.dev' },
    { word: 'Three.js',   counts: 70,  link: 'https://threejs.org' },
    { word: 'WebGL',      counts: 60 },
    { word: 'Threlte',    counts: 55,  link: 'https://threlte.xyz' },
    // 他のワードを追加...
  ];

  function handleWordClick(word: WordItem<{ link?: string }>) {
    if (word.link) window.open(word.link, '_blank');
  }
</script>

<WordCloud data={words} --wc-background="#0d0d1a" --wc-color="#7ec8e3">
  <WordCloudLabel>
    {#snippet label({ props })}
      <span {...props} style="position:absolute;width:1px;height:1px;overflow:hidden;clip:rect(0,0,0,0)">
        テクノロジーワードクラウド
      </span>
    {/snippet}
  </WordCloudLabel>

  <WordCloud3D fontUrl={FONT_URL} onWordClick={handleWordClick} />
</WordCloud>
```
