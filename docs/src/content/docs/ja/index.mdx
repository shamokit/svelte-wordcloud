## 謝辞

svelte-wordcloud は、2 つの素晴らしいオープンソースプロジェクトの上に成り立っています。
Threlte と troika-three-text の作者・コントリビューターの皆さんに、心からの感謝を捧げます。
お二つのライブラリなくして、このライブラリは存在しませんでした。
